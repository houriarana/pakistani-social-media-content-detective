🇵🇰 Pakistani Social Media Content Detective

📌 Business Question

"What type of social-media content gets Pakistani audiences to engage?"

📖 Project Overview

This project analyzes YouTube comments on Pakistani content to understand audience engagement and sentiment. Acting as a Junior Digital-Marketing Data Scientist, the goal was to scrape real comments, perform sentiment analysis, and discover data patterns to provide actionable marketing recommendations for Pakistani brands.

🛠️ Tools & Technologies

· Python (Data Processing & Scraping)
· YouTube Data API v3 (Data Extraction)
· Pandas (Data Cleaning & Manipulation)
· NLTK / VADER (Sentiment Analysis)
· Matplotlib & Seaborn (Exploratory Data Analysis / Graphs)

🚀 Methodology

1. Data Scraping: Extracted over 2000+ actual comments using YouTube Data API v3.
2. Data Cleaning: Removed duplicates, empty strings, and irrelevant text to create a processed dataset.
3. Sentiment Analysis: Classified comments into Positive, Negative, and Neutral categories.
4. EDA: Created visualizations (bar charts) to understand audience behavior and engagement patterns.

📂 Repository Contents

· scrape.py - Python script to fetch comments from YouTube.
· raw_comments.csv - The original, unprocessed data extracted from the API.
· sentiment.py - Script for cleaning data and running sentiment analysis.
· processed_sentiment.csv - Final dataset containing comments and their assigned sentiments.
· graphs.py - Script used to generate visual charts.
· sentiment_bar_chart.png - Visual representation of sentiment distribution.
